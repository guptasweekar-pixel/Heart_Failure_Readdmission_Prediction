Heart Failure 30-Day Readmission Prediction

Project Overview

This project uses machine learning classification models to predict whether a patient will be readmitted within 30 days after a heart-failure-related hospitalization.

Objectives

- Inspect and prepare the dataset.
- Train Logistic Regression, K-Nearest Neighbors (KNN), and Decision Tree models.
- Evaluate models using Accuracy, Precision, Recall, F1-score, ROC-AUC, and confusion matrices.
- Tune model hyperparameters and compare performance.
- Recommend a model based on evaluation results and the healthcare context.

Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Tuned versions of the models

Project Notebook

The Jupyter Notebook containing the code, analysis, visualizations, and model evaluation is available in this repository.

Dataset

The dataset was provided by the instructor. It is not included in this repository. Place the CSV file in the appropriate working folder before running the notebook, and ensure the filename matches the one used in the code.
